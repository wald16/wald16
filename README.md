## Proyectos destacados

**Homelab**
Servidor self-hosted con más de diez servicios corriendo en Docker Compose: Nextcloud, n8n, Portainer, RomM, Dashy, WireGuard, entre otros. Acceso remoto vía VPN con exposición selectiva a través de Cloudflare Tunnels. Con su propio pipeline de CI/CD para desplegar la infra como código.

**Stack de monitoreo**
Prometheus + Grafana + cAdvisor + Redis para observabilidad de contenedores, y Promtail + Loki para logs. Dashboards importados y personalizados, con variables de datasource configuradas dinámicamente.

**Notificaciones de CI a Telegram**
Plantilla reutilizable para avisar por Telegram el resultado de los pipelines de despliegue.

**Automatización de Planners**
Carga automática de planes y tareas en Microsoft Planner usando CLI for Microsoft 365 en Docker y un script en Python.

**Simulador de Daltonismo**

GNOME + PaperWM con una extensión propia para la barra, Firefox con tema minimal (negro/verde) y terminal Ghostty con zsh. Estética limpia: poca info, símbolos y color, sin bloat.
